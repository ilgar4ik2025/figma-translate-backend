## Protection Mechanism

### [PRESERVE] Naming Convention

Elements that should not be modified during localization are marked with the `[PRESERVE]` prefix in their layer names:

- `[PRESERVE] Background` - Background images generated by AI
- `[PRESERVE] iPhone Mockup` - iPhone mockup frames containing user screenshots

### How It Works

1. **Element Creation**: When SlideComposer creates backgrounds and mockups, it prefixes their names with `[PRESERVE]`

2. **Localization Filtering**: The `collectLocalizableTextNodes()` function filters out any elements whose names start with `[PRESERVE]`

3. **Text-Only Localization**: Only headline and subheadline text nodes are collected for localization, preserving all visual elements

### 2. Localization Filter Function

The `collectLocalizableTextNodes()` function implements the filtering logic:

```javascript
/**
 * Collect text nodes for localization, excluding elements marked with [PRESERVE]
 * This ensures that mockups and backgrounds created by Tab 2 are not modified during localization
 * @param {Array} nodes - Array of Figma nodes to search
 * @param {Array} acc - Accumulator for text nodes
 * @returns {Array} - Array of TextNodes that should be localized
 */
function collectLocalizableTextNodes(nodes, acc = []) {
  for (const node of nodes) {
    // Skip nodes marked with [PRESERVE] prefix
    if (node.name && node.name.startsWith('[PRESERVE]')) {
      continue;
    }
    
    // Add text nodes that are not in preserved containers
    if (node.type === 'TEXT') {
      acc.push(node);
    }
    
    // Recursively search children
    if ('children' in node) {
      collectLocalizableTextNodes(node.children, acc);
    }
  }
  return acc;
}
```

## Metadata Integration

In addition to the `[PRESERVE]` naming convention, protected elements also have metadata flags:

```javascript
// Background metadata
rect.setPluginData('preserve', 'true');

// Mockup metadata
mockupFrame.setPluginData('preserve', 'true');

// Screenshot metadata (child of mockup)
screenshotRect.setPluginData('preserve', 'true');
```

This provides a dual-layer protection mechanism:
1. **Name-based**: `[PRESERVE]` prefix for visual identification
2. **Metadata-based**: `preserve: 'true'` flag for programmatic checks

## Documentation for Tab 1 Users

### For Plugin Users

**Understanding Protected Elements:**

When you generate screenshots using Tab 2 (Screenshot Generator), certain visual elements are automatically protected from modification during localization:

- **Backgrounds**: AI-generated background images
- **iPhone Mockups**: The iPhone frame and any screenshots inside it

These elements are marked with `[PRESERVE]` in their layer names and will not be affected when you run localization.

**What Gets Localized:**

Only the text content is localized:
- Headlines
- Subheadlines

**What Stays the Same:**

Visual elements remain unchanged:
- Background images
- iPhone mockup frames
- User screenshots inside mockups
- Layout and positioning

### For Developers

**Extending the Protection System:**

To protect additional elements from localization:

1. **Add [PRESERVE] prefix** to the element name:
   ```javascript
   element.name = '[PRESERVE] My Element';
   ```

2. **Add metadata flag** (optional but recommended):
   ```javascript
   element.setPluginData('preserve', 'true');
   ```

3. **The element and all its children** will be automatically excluded from localization

**Custom Filtering:**

If you need custom filtering logic, you can modify `collectLocalizableTextNodes()`:

```javascript
function collectLocalizableTextNodes(nodes, acc = []) {
  for (const node of nodes) {
    // Add custom filtering logic here
    if (shouldSkipNode(node)) {
      continue;
    }
    
    if (node.type === 'TEXT') {
      acc.push(node);
    }
    
    if ('children' in node) {
      collectLocalizableTextNodes(node.children, acc);
    }
  }
  return acc;
}
```
